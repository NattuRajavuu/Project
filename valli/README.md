# Luxe Atelier

A premium React + Vite ecommerce demo with Tailwind CSS, Framer Motion animations, mock product data, cart state, wishlist state, dark mode, checkout simulation, and responsive pages.

## Run with Python

This repo now includes a Python-runnable static version that does not require Node, npm, Flask, or pip.

```bash
python app.py
```

Open:

```text
http://localhost:8000
```

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Pages

- Home
- Product listing
- Product details
- Shopping cart
- Checkout
- Login / register
- User profile dashboard
- Wishlist
- Order success
